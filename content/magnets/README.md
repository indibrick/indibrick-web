# IndiBrick Lead-Gen Magnets

Five Markdown source files for the lead-magnet PDFs the competitive audit
recommended. Each is written to be self-contained: hand any file to a
designer (or a Markdown → PDF pipeline like Pandoc + wkhtmltopdf) and you
get a delivery-ready PDF.

Cover pages should include: IndiBrick logo, FSRA #12830, "Reviewed by
[named broker], License Level [1/2/Broker]", and a "download date" stamp
so recipients see the version they received.
